# Prática de Programação

Repositório criado para praticar programação, lógica e diferentes tecnologias
durante minha formação em Inteligência Artificial e relembrar linguagens backend usadas na Faculdade de Sistemas de informação.

## Objetivo

Este repositório reúne exercícios pequenos e independentes desenvolvidos
para praticar fundamentos de programação, estruturas de dados, orientação
a objetos, APIs, desenvolvimento web e outros conceitos.

Cada exercício foi desenvolvido de forma independente, com o objetivo de
praticar um conceito específico.

## Linguagens e tecnologias

- Python
- Java
- C#
- PHP
- JavaScript
- Node.js
